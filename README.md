# Bhutan Public Procurement Transparency Platform (BlockOps)

## Overview
This platform is designed to enhance transparency and accountability in the public procurement process of Bhutan using blockchain technology. 

## Features
- **Transparent Bidding**: All bids are recorded on-chain for public auditing.
- **Agency Dashboard**: For government agencies to manage procurement requests.
- **Bidder Portal**: For vendors to participate in tenders.
- **Transparency Portal**: Public-facing interface for monitoring procurement activities.

## Technology Stack
- **Frontend**: Next.js / Vite (React)
- **Blockchain**: Solidity / Hardhat
- **Styling**: Vanilla CSS / Premium Design System

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
